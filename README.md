Instructions for running:

Step 1: unzip the folder, then navigate to the code directory

Step 2: add the two datasets to the data folder

Step 3 (with uv): uv run python algorithm/experiments.py

Step 3 (no uv): pip install requirements.txt 

python algorithm/experiments.py

Step 4: inspect the results folder, which should be next to algorithm and data

Alternatively, you can run algorithm/pipeline.py for an individual run with any desired parameters, as well as algorithm/test.py for some basic testcases
